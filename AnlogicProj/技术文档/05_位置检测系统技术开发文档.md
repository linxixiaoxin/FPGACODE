# 05 — 位置检测系统技术开发文档

> **所属项目**: AxisesCTRL (四轴伺服驱动器 FPGA)  
> **涉及目录**: `PositionDetection/`  
> **关键模块**: PositionDetection, EncoderDrivers, EncoderSelect, ABZDriver, LiteBISSCProtocol, LiteDMCProtocol, ElectricalAngleDeal, SinCosCal, EAnglesCalScheduler

---

## 1. 模块概述

位置检测系统支持三种编码器类型，为四轴独立提供机械位置读取和电气角度计算（sin/cos输出），供FOC电流控制器使用。

### 1.1 支持的编码器类型

| 编码器 | 协议 | 物理接口 | 精度 |
|--------|------|---------|------|
| ABZ 增量式 | 正交脉冲 | 差分/单端3线 | 32-bit计数器 |
| BISS-C 绝对值 | 同步串行 | MA/CLK/DATA | 26-bit位置 |
| DMC 通信式 | UART (RS-485) | 半双工485 | 24-bit位置 |

### 1.2 模块层次

```
PositionDetection.v
├── RegSpcae_PositionDetection.v         ← 寄存器接口
├── EncoderDrivers.v                     ← 编码器驱动 (4轴)
│   └── EncoderSelect.v ×4              ← 编码器类型选择
│       ├── ABZDriver.v                  ← ABZ 增量编码器
│       ├── LiteBISSCProtocol.v          ← BISS-C 绝对值协议
│       └── LiteDMCProtocol_NonStandardCalibration.v  ← DMC 通信协议
│           ├── LiteDMCProtocol.v
│           ├── NonStandardCalibration.v
│           ├── UARTServiceForDMC.v
│           ├── UART_BYTETX_forDMC.vhd
│           └── UART_BYTERX_forDMC.vhd
└── EAnglesCalScheduler.v                ← 电气角度计算调度
    └── ElectricalAngleDeal.v ×4        ← 单轴角度计算
        └── SinCosCal.v ×2              ← CORDIC sin/cos (×2: 正+补偿)
```

## 3. ABZ增量编码器 (ABZDriver.v)

### 3.1 接口

| 端口 | 方向 | 位宽 | 描述 |
|------|------|------|------|
| `PluseA` | in | 1 | A相脉冲 |
| `PluseB` | in | 1 | B相脉冲 (正交于A) |
| `PluseZ` | in | 1 | Z相索引脉冲 (每圈一次) |
| `PluseCounter[31:0]` | out | 32 | 位置计数值 |

### 3.2 方向判定 (格雷码状态机)

```
PluseState = {PluseA_Sync, PluseB_Sync} (2-bit格雷码)

状态转换:
  00 → 01 → 11 → 10 → 00  (正向 = 递增)
  00 → 10 → 11 → 01 → 00  (反向 = 递减)

边沿检测:
  任何 A或B的边沿 → CountPluse 脉冲
  CountDir = 1 (递增) 或 0 (递减)
```

### 3.3 位置计数器

```verilog
// 初始化: 0x7FFFFFFF (中间值, 避免绕零问题)
// Z脉冲: 清零到 0
// A/B边沿: 根据方向 ±1

always @(posedge clk or negedge rst) begin
    if (!rst)
        PluseCounter <= 32'h7FFFFFFF;
    else if (Z_edge)
        PluseCounter <= 32'd0;
    else if (CountPluse && CountDir)
        PluseCounter <= PluseCounter + 1;
    else if (CountPluse && !CountDir)
        PluseCounter <= PluseCounter - 1;
end
```

## 4. BISS-C绝对值编码器 (LiteBISSCProtocol.v)

### 4.1 协议时序

```
MA  ────┐         ┌──────────────────
         └─────────┘  (主控请求脉冲)
         
CLK ──────┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─
          └─┘ └─┘ └─┘ └─┘ └─┘ └─┘  (编码器时钟)
          
DATA ──────┘ └─┘ └─┘ └─┘ └─┘ └─┘ └─
         Ack Start  D25 D24 ...  D0  (数据位)
```

### 4.2 关键参数

| 参数 | 值 | 描述 |
|------|-----|------|
| `BISSCLK_CNTSET` | 39 | 时钟周期 = 40 clk = 400ns → 2.5MHz |
| `BISSCLK_NedgeSET` | 19 | 下降沿在计数一半处 |
| `BISSCLK_RedgeSET` | 39 | 上升沿在计数值处 |
| `DataBitsSet` | 34 | 最大数据位宽 |
| `TimeoutSet` | 40000 | 超时 = 400μs @ 100MHz |

### 4.3 接收状态机

| 状态 | 值 | 操作 |
|------|-----|------|
| 等待应答 | 0 | 检查DATA=1 (从设备应答) |
| 已应答 | 1 | 等待START=1 |
| 已启动 | 2 | 等待CDS=0 (起始位结束) |
| 接收数据 | 3 | 接收 DataBitsSet 位 |
| 完成 | 4 | 置位 DataValid |
| 错误 | 15 | 超时 → 置位 ENCNoResponsPluse |

### 4.4 数据提取

```verilog
// DataBitRXCNT 从0计数到DataBitsSet
if (DataBitRXCNT <= 25)
    PositionFB[DataBitRXCNT] <= BISS_DATAIN_Sync;

// DataValid 在 DataBitRXCNT == 30 时置位
```

## 5. DMC通信协议编码器 (LiteDMCProtocol.v)

### 5.1 物理层

- **接口**: RS-485 半双工 (一对差分线)
- **波特率**: ~2.5 Mbps (100MHz / 40)
- **UART**: 1起始位 + 8数据位 + 1停止位

### 5.2 标准读取协议

```
FPGA → DMC: 发送 0x02 (请求位置)
DMC → FPGA: 返回11字节帧

响应帧结构:
  Byte0: (前导/帧头)
  Byte1: (前导/帧头)
  Byte2: PositionFB[7:0]  (LSB)
  Byte3: PositionFB[15:8]
  Byte4: PositionFB[23:16] (MSB)
  Byte5-10: (尾部/校验)

PositionFB = {8'd0, Byte4, Byte3, Byte2}  // 24-bit → 32-bit
```

### 5.3 非标准校准协议 (NonStandardCalibration.v)

**校准状态机**:

| 状态 | 操作 |
|------|------|
| IDLE (0) → START (1) | 收到 CalibrationEN 触发 |
| SEND_CMD_3A (1→2) | 发送校准命令 0x3A |
| WAIT_ACK_A3 (2→12) | 等待 0xA3 应答 |
| RETRY_LOOP (12→1/3) | 最多重试9次 (20ms间隔) |
| SEND_CMD_3B (3→4) | 发送状态查询 0x3B |
| WAIT_COMPLETE (4→10/14) | 等待 0xB3 (完成) 或 0x04 (忙) |
| RETRY_STATUS (14→3) | 重试状态查询 |
| DONE (10) | 校准完成 |

**超时参数**:
```verilog
parameter DelayCountRef = 2_000_000;  // 20ms @ 100MHz
parameter TXEN_DelayCNT_SET = 12;     // TX使能延迟
```

### 5.4 UART接收器 (UART_BYTERX_forDMC.vhd)

**三重过采样抗噪**:
```vhdl
-- 每bit采样3次 (Samping1, Samping2, Samping3)
-- 多数表决:
RXD_samp <= RXD_samp(1 downto 0) & RXD_Input;
if (RXD_samp = "001" or RXD_samp = "011" or RXD_samp = "101" or RXD_samp = "111") then
    RXD_Filter <= '1';
else
    RXD_Filter <= '0';
end if;
```

## 6. 电气角度计算 (ElectricalAngleDeal.v)

### 6.1 数据流

```
MechanicalPosition[31:0] (编码器原始值)
        │
        ▼
    ┌──────────────┐
    │ HW_MULT_U3232 │  MechanicalPosition × TransCoeff
    │ 32×32 → 64   │  TransCoeff: 32-bit Q16
    └──────┬───────┘
           │ Result[31:16] (Q16格式)
           ▼
    Etheta_pre = Q16 角度
           │
           ▼
    ┌──────────────────────┐
    │ Polarity + ZeroSet   │
    │ if Polarity=1:       │
    │   Etheta = Etheta_pre - ZeroSet
    │ else:                │
    │   Etheta = ZeroSet - Etheta_pre
    │                      │
    │ if VirtualThetaEN:   │
    │   Etheta = VirtualTheta (开环)
    └──────┬───────────────┘
           │
           ▼
    ┌──────────┐     ┌──────────────┐
    │ SinCosCal │ →   │ SINval/COSval │ (主角度)
    │ ThetaIn   │     └──────────────┘
    └──────────┘
    
    ┌──────────┐     ┌──────────────────┐
    │ SinCosCal │ →   │ InvSIN/InvCOS    │ (补偿角度)
    │ ThetaIn+  │     └──────────────────┘
    │ InvComp   │
    └──────────┘
```

### 6.2 计算步骤状态机

| CNT状态 | 操作 |
|---------|------|
| Idel (0) | 等待 trig |
| GetTransedAngle (1) | 锁存乘法结果 → Etheta_pre |
| PolarityZeroSet (2) | 应用极性、零位偏移、虚拟角度覆盖 |
| Angle1Input (3) | ThetaIn ← Etheta, 触发SinCosCal |
| Angle1Cal (4) | 等待完成 → 捕获 SIN/COS |
| Angle2Input (5) | ThetaIn ← Etheta + InvTransAngleComp |
| Angle2Cal (6) | 等待完成 → 捕获 InvSIN/InvCOS |
| AllCalFinish (7) | 置位 finish, 返回 IDLE |

## 7. CORDIC Sin/Cos计算 (SinCosCal.v)

### 7.1 算法原理

CORDIC (COordinate Rotation DIgital Computer) 通过迭代旋转逼近sin/cos值。

**输入**: ThetaIn [0, 360°) Q16格式  
**输出**: SINval, COSval Q15有符号

### 7.2 象限压缩

```
将 [0, 360°) 压缩到 [0, 90°):
  Quadrant = ThetaIn[15:14]  (最高2位)
  
  Q00 (0-90°):    theta = ThetaIn
  Q01 (90-180°):  theta = ThetaIn - 90°
  Q10 (180-270°): theta = ThetaIn - 180°
  Q11 (270-360°): theta = ThetaIn - 270°
```

### 7.3 CORDIC迭代

```verilog
// 初始化
x0 = K = 16'h4DB9  (≈ 0.60725)
y0 = 0
z0 = theta (压缩后的角度)

// 16次旋转 (i = 0 .. 15)
for each i:
    if (z[i] >= 0) begin
        x[i+1] = x[i] - (y[i] >>> i);  // 顺时针旋转
        y[i+1] = y[i] + (x[i] >>> i);
        z[i+1] = z[i] - arctan(2^(-i));
    end else begin
        x[i+1] = x[i] + (y[i] >>> i);  // 逆时针旋转
        y[i+1] = y[i] - (x[i] >>> i);
        z[i+1] = z[i] + arctan(2^(-i));
    end
```

### 7.4 arctan查找表

| i | arctan(1/2^i) Q16 | 角度(度) |
|---|-------------------|---------|
| 0 | 0x3243 (12867) | 45.0° |
| 1 | 0x1DAC (7596) | 26.57° |
| 2 | 0x0FAD (4013) | 14.04° |
| 3 | 0x07F5 (2037) | 7.13° |
| 4 | 0x03FE (1022) | 3.58° |
| ... | ... | ... |
| 15 | ≈ 0.0028° |

### 7.5 象限恢复

```verilog
case (Quadrant)
    Q00: begin SIN = y16;  COS = x16;  end
    Q01: begin SIN = x16;  COS = -y16; end
    Q10: begin SIN = -y16; COS = -x16; end
    Q11: begin SIN = -x16; COS = y16;  end
endcase
```

**总延迟**: 16 clk

## 8. 四轴调度 (EAnglesCalScheduler.v)

### 8.1 调度策略

```
轮询调度:
  - DataValidRec[3:0]: 记录哪些轴有有效编码器数据
  - ValidNum: 有效轴的数量
  - DealCNT: 已处理轴计数
  - TobeDeal: DataValidRec & (~DealedRec): 待处理掩码
  - Sel: 从TobeDeal中选择最低有效位对应的轴号

优先级: 轴1 > 轴2 > 轴3 > 轴4 (低位优先)
```

### 8.2 超时处理

```verilog
// TimeCriticalPluse 是来自载波模块的定时脉冲
// 在此脉冲时检查哪个轴尚未处理完毕
if (TimeCriticalPluse && !DealedRec[axis])
    CALOvertime[axis] = 1'b1;  // 标记超时
```

## 10. TransCoeff计算

```
TransCoeff = (极对数 × 编码器分辨率) / 2^16

示例:
  4对极电机, 17-bit BISS-C (131072 counts/rev)
  TransCoeff = 4 × 131072 / 65536 = 8.0 = Q16(8 × 65536)
  
  含义: 每单位机械位置变化对应8单位电气角度变化
```

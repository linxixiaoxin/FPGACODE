# 02 — 总线互连系统技术开发文档

> **所属项目**: AxisesCTRL (四轴伺服驱动器 FPGA)  
> **涉及目录**: `BusInterconnecter/` (27个源文件)  
> **关键模块**: BusInterconnecter, MultiAccessPreDeal, AccessLocalspcae, SlaveSPICtrl, AsyncBusInterface_Renesas, BusTimingConv_DataAddrMultiplex_Async, ZlinkslavestationShell, UdpInteraction, StandardDebugModule

---

## 1. 系统概述

总线互连系统是FPGA内部与外部的数据通信中枢。它提供**双主控 → 8从设备**的共享总线架构，支持5种外部物理接口（Renesas异步总线、STM32/GD32 FSMC、SPI从机、UART调试、UDP/RMII以太网）。

### 1.1 设计目标

- 统一的16位寄存器地址空间，简化MCU软件访问
- 多主控仲裁，支持同时连接调试接口和运行总线
- 地址译码与访问路由的确定性延迟（2周期）
- 跨时钟域安全同步


## 2. 总线拓扑

### 2.1 整体架构

```
                 外部物理接口
        ┌──────────┬──────────┐
        │          │          │
   [Renesas]  [STM32/GD32]  [SPI]
   异步总线     FSMC复用      从机
        │          │          │
   ┌────┴──────────┴──────────┴────┐
   │     Master1Sel[3:0] 选择      │
   │  1=Renesas  2=STM32  3=SPI   │
   └──────────────┬────────────────┘
                  │ FPGA_RE/WE/XA/XD
   ┌──────────────┴────────────────┐
   │   MultiAccessPreDeal          │
   │   固定优先级: Master1 > Master2│
   └──────┬──────────────┬─────────┘
          │              │
     Master1通道     Master2通道
          │              │
   ┌──────┴──────────────┴─────────┐
   │   AccessLocalspcae            │
   │   地址译码 → 8从设备通道       │
   │   2周期流水线延迟              │
   └──┬──┬──┬──┬──┬──┬──┬──┬──────┘
      │  │  │  │  │  │  │  │
     Ch0 Ch1 Ch2 Ch3 Ch4 Ch5 Ch6 Ch7
```

### 2.2 内部总线信号定义

| 信号 | 宽度 | 方向 | 描述 |
|------|------|------|------|
| `ADDR[15:0]` | 16 | M→S | 基地址偏移（由AccessLocalspcae减法计算） |
| `WRDATA[15:0]` | 16 | M→S | 写数据 |
| `RDLWRH` | 1 | M→S | 读/写选择 (1=读, 0=写) |
| `CS` | 1 | M→S | 片选 (地址命中) |
| `RDDATA[15:0]` | 16 | S→M | 读数据 |
| `RDDATAVALID` | 1 | S→M | Master1读应答 (脉冲) |
| `WRACK` | 1 | S→M | Master2写应答 (脉冲) |

### 2.3 访问时序

```
         T0      T1      T2      T3
clk    ─┐  ┌─┐  ┌─┐  ┌─┐  ┌─┐  ┌─
        └──┘  └──┘  └──┘  └──┘  └

CS     ──────┐     ┌────────────── (Master1输入)
             └─────┘
             
D_CS   ──────┐     ┌────────────── (仲裁后，T0)
             └─────┘

_0stclk ─────┐    ┌─────────────── (组合译码，T0)
             └────┘

_CS    ──────────┐     ┌────────── (寄存器输出，T1)
                 └─────┘

ADDR   ──────────┐     ┌────────── (偏移地址，T1)
                 └─────┘

RDDATA ────────────────┐     ┌──── (从设备返回，T2)
                       └─────┘

RDDATAVALID ───────────┐     ┌──── (应答，T2)
                       └─────┘
```

**总延迟**: 2个时钟周期 (T0→T2)，确定性无等待。

## 3. 多主仲裁 (MultiAccessPreDeal.v)

### 3.1 仲裁策略

```
优先级: Master1 > Master2 (固定优先级)

仲裁逻辑:
  Mst1_CS = FPGA_RE || FPGA_WE
  Mst2_CS_pre = UserSpace_RD || UserSpace_WR

  if (Mst1_CS && Mst2_CS_pre) → 冲突
      Mst2 被抑制1周期，请求延迟重放
      Mst1 立即获得总线
  else if (Mst1_CS) → Master1 获得总线
  else if (Mst2_CS) → Master2 获得总线

访问源编码:
  D_AccessSource = 0 → Master1
  D_AccessSource = 1 → Master2
```

### 3.2 冲突处理时序

```
clk     ─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─┐ ┌─
         └─┘ └─┘ └─┘ └─┘ └─┘ └─┘

Mst1_CS ────┐   ┌──────────────
            └───┘
Mst2_CS ────┐   ┌────────────── (同时请求)
            └───┘
Collision ──┐   ┌──────────────
            └───┘
Mst2_dly ───────┐   ┌────────── (延迟1周期)
                └───┘
D_CS     ────┐   ┌─┐   ┌────── (Mst1先→Mst2后)
            └───┘ └───┘

结果: Mst1访问完成于T2, Mst2访问完成于T3
```

### 3.3 局限性

- **无公平性**: Master1连续访问会饿死Master2
- **Mst2吞吐量**: 最坏情况 = 50% (每个Mst1访问导致1周期抑制)
- **适用场景**: Master2用于调试/监控（低带宽容忍延迟），Master1用于实时控制（不容忍延迟）

## 4. 地址译码 (AccessLocalspcae.v)

### 4.1 地址空间分配

| 通道 | 基地址 | 结束地址 | 大小(字) | 外设模块 |
|------|--------|---------|---------|---------|
| Ch0 | `16'h0000` | `16'h00FF` | 256 | Debug/Reserve (Reservespace) |
| Ch1 | `16'h0100` | `16'h01FF` | 256 | CurrentSample |
| Ch2 | `16'h0200` | `16'h02FF` | 256 | PositionDetection |
| Ch3 | `16'h0300` | `16'h06FF` | 1024 | AxisesCurrentCtrler |
| Ch4 | `16'h0700` | `16'h077F` | 128 | CarrierModule |
| Ch5 | `16'h0780` | `16'h07FF` | 128 | UnrelatedSigSample |
| Ch6 | `16'h0800` | `16'h087F` | 128 | SafetyMonitor |
| Ch7 | `16'h0880` | `16'h08FF` | 128 | OverAllControl (预留) |

### 4.2 地址译码逻辑

```verilog
// 组合译码 (0stclk)
wire Ch1_CS_0stclk = D_CS && (D_ADDR >= 16'h0100) && (D_ADDR <= 16'h01FF);
wire Ch2_CS_0stclk = D_CS && (D_ADDR >= 16'h0200) && (D_ADDR <= 16'h02FF);
// ... 以此类推

// 寄存器输出 (1stclk)
reg Ch1_CS_1stclk;
always @(posedge clk) Ch1_CS_1stclk <= Ch1_CS_0stclk;

// 偏移地址计算
wire [15:0] Ch1_ADDR = D_ADDR - 16'h0100;  // 基地址减法
```

### 4.3 读数据多路复用

```verilog
// 2stclk: 多路复用选择 + 应答生成
always @(posedge clk) begin
    if (DebugReserve_CS_2stclk)
        D_RDDATA <= DebugReserve_RDDATA;
    else if (CurrentSample_CS_2stclk)
        D_RDDATA <= CurrentSample_RDDATA;
    else if (PositionSample_CS_2stclk)
        D_RDDATA <= PositionSample_RDDATA;
    // ... 其余通道
end
```

## 5. 外部总线接口

### 5.1 Renesas 异步总线 (AsyncBusInterface_Renesas.v)

**物理接口**: 分离地址/数据总线，SRAM-like时序

| MCU信号 | FPGA端口 | 方向 | 描述 |
|---------|---------|------|------|
| `XCS` | AsyncCS | in | 片选 (低有效) |
| `XRD` | AsyncRD | in | 读选通 (低有效) |
| `XWE0` | AsyncWE0 | in | 写选通 (低字节) |
| `XA[15:0]` | AsyncADDRBus[15:0] | in | 地址总线 |
| `XD[15:0]` | AsyncDATABus[15:0] | inout | 双向数据总线 |
| `NADV` | AsyncNADV | in | 地址有效 |

**时序转换**:
```
MCU XRD _____/‾‾‾‾‾‾‾\_____  →  FPGA_RE: 下降沿脉冲 (Redge)
MCU XWE _____/‾‾‾‾‾‾‾\_____  →  FPGA_WE: 上升沿脉冲 (Redge)

同步链: XCS → _dly1 → _sync → 边沿检测
        XRD → _dly1 → _sync → _sync_dly → 边沿检测
        XWE → _dly1 → _sync → _sync_dly → 边沿检测

CS门控: XRD_dly1 = XRD || XCS  (CS无效时屏蔽RD脉冲)
```

**数据保持**: `DataLocked` 寄存器在 `FPGA_XDinValid` 时更新，维持输出直到下一次有效读取。

### 5.2 STM32/GD32 FSMC 接口 (BusTimingConv_DataAddrMultiplex_Async.v)

**与Renesas的关键差异**: 地址/数据复用在同一16位总线上

```
FSMC时序:
  NADV ──\___________/‾‾‾‾‾‾  (地址有效脉冲)
  XD[15:0] ──<ADDR>──<DATA>──  (复用总线)
  
地址锁存: NADV下降沿 → 捕获XD上的地址
数据访问: XRD下降沿 (读) / XWE上升沿 (写)

同步链: 三级_dly1/_dly2/_dly3
地址锁存器: FPGA_XA 在 NADV检测 (Nedge) 时从 XDin 更新
```

### 5.3 SPI从机 (SlaveSPICtrl.v)

**SPI模式**: Mode 3 (CPOL=1, CPHA=1) — 空闲高电平，上升沿采样，下降沿变化

**帧格式 (40-bit)**:

```
Bit:  39 38 ... 24 | 23 22 21 20 19 | 18 | 17 16 | 15 ... 0
     ┌─────────────┼────────────────┼────┼───────┼──────────┐
     │ DATAIN[15:0]│    (gap)       │Vld │CMD[1:0│ADDR[15:0]│
     └─────────────┴────────────────┴────┴───────┴──────────┘
      MSB first                                              LSB first
```

**命令编码**:

| CMD[1:0] | 操作 |
|----------|------|
| 00 | 无操作 |
| 01 | 读 |
| 10 | 写 |
| 11 | 读写 |

**位计数与应答**:

| Bit范围 | 动作 |
|---------|------|
| 0-15 | MOSI采样 → ADDR移位寄存器 |
| 16-17 | MOSI采样 → CMD |
| 18 | MOSI采样 → AccessMsgValid标志 |
| 19-22 | (无采样) |
| 23 | MISO开始驱动 → RDDATALocked[15] |
| 24-38 | MISO驱动 → RDDATALocked[14:0] (读数据返回) |
| 39 | SPI_SEL释放 → SPItrans_end → 锁存CMD/WDATA/ADDR |

**跨域同步**:
```
SPI_CLK域 → 100MHz域:
  AccessMsgValid → _sync1(SPI_CLK) → _sync2(clk) → _sync3(clk)
  → Redge检测 → AccessMsgValid_syncpluse
  
  SPItrans_end → _sync1_dly → _sync2_dly → SPItrans_endPluse
```

## 6. 主设备选择配置

### 6.1 Master1Sel / Master2Sel 编码

| 值 | Master1 | Master2 |
|----|---------|---------|
| 0 | 禁用 | 禁用 |
| 1 | **Renesas异步总线** (默认) | UART调试模块 |
| 2 | STM32/GD32 FSMC | **UDP/RMII** (默认) |
| 3 | SPI从机 | Zlink从站 |

### 6.2 当前配置 (AppEnvironment.v)

```verilog
.Master1Sel(4'd1),   // Renesas异步总线
.Master2Sel(4'd2),   // UDP/RMII以太网
```

### 6.3 备选配置

**48V驱动板 + Zlink通信**:
```verilog
.Master1Sel(4'd1),
.Master2Sel(4'd3),   // ZlinkSlave
```

同时需在 `BusInterconnecter.v` 中启用ZlinkSlave的PHY0接口并屏蔽UdpInteraction，因为两者共享PHY0引脚。

### 7.1 接口

| 端口 | 方向 | 描述 |
|------|------|------|
| `clk` | in | 系统时钟 |
| `rst` | in | 复位 |
| `FrameDealTrigSource` | in | 8kHz帧触发 (~125μs) |
| `FrameTXTrigActiveCNTSet[15:0]` | in | TX间隔设置 (=7, 表示每8个触发发一次 = 1ms) |
| `RXD` | in | UART接收 (单线串行) |
| `TXD` | out | UART发送 (单线串行) |
| `UserSpace_RD/WR/ADDR/WRDATA` | out | 总线主控接口 |
| `UserSpace_RDDATA/RDDATAVALID/WRACK` | in | 总线应答 |

### 7.2 功能

- **UART串行 ↔ 并行寄存器访问**转换
- **帧协议**: 基于8kHz触发源的周期性帧收发
- **波特率**: 未知 (网表中编码)
- **TX间隔**: `FrameTXTrigActiveCNTSet=7` → 每8个触发(1ms)发送一次

## 9. 系统顶层集成要点

### 9.1 地址总线移位 (AppEnvironment.v)

```verilog
.AsyncADDRBus({1'b0, AsyncADDRBus[15:1]}),
```

**原因**: 外部MCU使用字节地址（8位编址），FPGA内部使用16位字地址。右移1位将字节地址转换为字地址。

**效果**:
| MCU地址 (字节) | FPGA内部地址 (字) |
|---------------|------------------|
| 0x0000 | 0x0000 |
| 0x0002 | 0x0001 |
| 0x0100 | 0x0080 |
| 0x0200 | 0x0100 (CurrentSample基地址) |

### 9.2 三态总线控制

```verilog
assign AsyncDATABus = (!AsyncCS && !AsyncRD) ? AsyncDATABus_out : 16'hzzzz;
```

仅在MCU发起读操作 (`CS=0, RD=0`) 时驱动数据总线，否则释放为高阻态。

### 9.3 异步总线调试捕获

AppEnvironment.v中包含一组调试寄存器 (`synthesis keep = 1`)，捕获所有异步总线信号:
```verilog
reg [15:0] ADDR_lock, DATA_lock;
reg CS_lock, WE0_lock, RD_lock, WAIT_lock, BS_lock, NADV_lock;
// 每个时钟周期更新，用于SignalTap/逻辑分析仪观察
```

## 10. 设计要点与约束

### 10.1 关键时序路径

| 路径 | 约束 | 裕量 |
|------|------|------|
| MCU地址→FPGA内部 (异步同步) | 无约束 (异步域) | — |
| SPI_CLK→100MHz域同步 | 无约束 (异步域) | — |
| PHY_REFCLK→100MHz域 (FIFO) | 无约束 (异步域) | — |
| 内部总线→从设备→返回 | <10ns (100MHz) | 充裕 |

### 10.2 设计约束

1. **每个从设备必须在2周期内返回读数据** — 地址命中后第2周期RDDATA有效
2. **写操作无需应答** — 写数据在第1周期直接送到从设备 (组合逻辑)
3. **片选信号与地址/数据同步** — 确保从设备只在CS有效时响应
4. **Master2不应在实时控制期间高频访问** — 避免冲突导致的延迟

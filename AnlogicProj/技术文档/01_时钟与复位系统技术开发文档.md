# 01 — 时钟与复位系统技术开发文档

> **所属项目**: AxisesCTRL (四轴伺服驱动器 FPGA)  
> **目标器件**: Anlogic EG4X20BG256  
> **涉及文件**: `SysPLL.v`, `ESCPLL.v`, `AnlogicPLL.v/vhd`, `AnlogicPLL.ipc`, `TimeConstraint.sdc`

---

## 1. 模块概述

时钟与复位系统为整个FPGA设计提供稳定的时钟源和同步复位信号。系统采用Anlogic EG4系列硬PLL IP (EG_PHY_PLL)，从单路外部输入时钟生成三个频率的同步时钟域，并通过同步器链保证复位的可靠释放。

### 1.1 模块层次

```
SysPLL.v                     ← 用户逻辑封装
  └── ESCPLL.v               ← PLL IP封装
        └── AnlogicPLL.v     ← 硬IP原语网表 (EG_PHY_PLL)
```

### 1.2 端口定义 (SysPLL.v)

| 端口 | 方向 | 位宽 | 描述 |
|------|------|------|------|
| `clk` | in | 1 | 外部晶振输入 (50MHz 或 25MHz) |
| `reset` | in | 1 | 外部异步复位 (低有效)，来自AppEnvironment上电复位 |
| `reset_sync` | out | 1 | 同步化系统复位输出 (高有效) |
| `Clk_50Mhz` | out | 1 | 50MHz时钟输出 |
| `Clk_100Mhz` | out | 1 | 100MHz主系统时钟 |
| `Clk_20Mhz` | out | 1 | 20MHz ADC/编码器时钟 |
| `SysResetSig` | in | 1 | 软件系统复位请求 (来自SafetyMonitor) |

## 3. 时钟域架构

### 3.1 时钟树

```
外部晶振 ──→ FPGA clk引脚 (F1)
               │
               └── SysPLL (EG_PHY_PLL)
                    ├── C0: Clk_50Mhz  ──→ BusInterconnecter (clk50M),
                    │                      复位同步域
                    ├── C1: Clk_100Mhz ──→ 主系统逻辑:
                    │                      - BusInterconnecter
                    │                      - CarrierModule/PwmGen
                    │                      - AxisesCurrentCtrler
                    │                      - SafetyMonitor
                    │                      - 各寄存器空间
                    └── C2: Clk_20Mhz  ──→ 低速外设:
                                           - Sinc3Driver (ADC滤波)
                                           - EncoderDrivers (编码器协议)
                                           - ABZDriver/BISSC/DMC UART
```

### 3.2 异步时钟域 (SDC声明)

| 时钟域 | 来源 | 频率 | SDC约束 |
|--------|------|------|---------|
| CLKin | 端口clk | 100MHz (PLL参考) | `create_clock period 10` |
| CLK100Mhz | PLL C1 | 100MHz | `create_generated_clock ×1` |
| CLK50Mhz | PLL C0 | 50MHz | `create_generated_clock ×0.5` |
| CLK20Mhz | PLL C2 | 20MHz | `create_generated_clock ×0.2` |
| SPICLK | 端口SPI_CLK | 20MHz | `create_clock period 50` |
| PHY1REFCLK50 | 端口PHY_REFCLK | 50MHz | `create_clock period 20` |
| PHY2REFCLK50 | 端口PHY_REFCLK2 | 50MHz | `create_clock period 20` |
| rstin | 虚拟时钟 | 1kHz | `create_clock period 1000` |

**所有时钟组声明为互斥 (`set_clock_groups -exclusive`)**，即任意两个时钟域之间的跨域路径不做时序分析，设计要求使用正确的同步器。

### 3.3 跨时钟域同步策略

| 跨域路径 | 同步方式 | 实现位置 |
|---------|---------|---------|
| 20MHz → 100MHz (ADC数据) | 三级寄存器链 + DataValid边沿检测 | Sinc3Driver.v |
| PHY_REFCLK → 100MHz (RMII) | 异步FIFO (双端口SRAM) + 握手 | Stream2bitTo1bit.v |
| 100MHz → PHY_REFCLK (RMII TX) | 异步FIFO (双端口SRAM) + 握手 | Stream1bitTo2bit.v |
| SPI_CLK → 100MHz (SPI命令) | 三级同步器 + 边沿检测器 | SlaveSPICtrl.v |
| 外部复位 → 50MHz | 双触发器同步器 | SysPLL.v |
| 外部IO → 100MHz | 双触发器同步器 | 各模块 |

## 4. 复位系统

### 4.1 复位层次

```
┌─────────────────────────────────────────────────┐
│ Level 1: 上电复位 (POR)                          │
│   AppEnvironment.v: CNT0[7:0] 计数 0→254         │
│   约 5.08μs 后释放 rstin                         │
│   生成: rstin (低有效脉冲)                        │
└──────────────────┬──────────────────────────────┘
                   ▼
┌─────────────────────────────────────────────────┐
│ Level 2: PLL初始化 (SysPLL.v)                    │
│   内部 init 计数器 (6位) 计数 0→63                │
│   约 1.28μs 后释放 PLL areset                    │
│   确保PLL稳定后时钟才有效                          │
└──────────────────┬──────────────────────────────┘
                   ▼
┌─────────────────────────────────────────────────┐
│ Level 3: 复位同步化 (SysPLL.v)                    │
│   双触发器同步器: Clk_50Mhz域                     │
│     reset → reset_sync1 → reset_sync2            │
│   系统复位保持: 计数器 0→200 (4μs)                │
│   输出: reset_sync (高有效, 同步释放)             │
└──────────────────┬──────────────────────────────┘
                   ▼
┌─────────────────────────────────────────────────┐
│ Level 4: 软件复位 (SysPLL.v + SafetyMonitor.v)   │
│   SysResetSig (来自 SafetyMonitor)               │
│   写 SysResetCTRL = 0xFFAA 触发                   │
│   同步化后驱动 reset_sync                         │
└─────────────────────────────────────────────────┘
```

### 4.2 SysPLL复位状态机

```verilog
// 伪代码逻辑
// PLL初始化
reg [5:0] init_cnt;
always @(posedge clk or negedge reset)
    if(!reset) init_cnt <= 0;
    else if(init_cnt != 63) init_cnt <= init_cnt + 1;
assign init = (init_cnt == 63);  // ~1.28μs @ 50MHz

// PLL areset = !init

// 复位双触发同步
reg reset_sync1, reset_sync2;
always @(posedge Clk_50Mhz or negedge reset)
    if(!reset) {reset_sync2, reset_sync1} <= 2'b00;
    else       {reset_sync2, reset_sync1} <= {reset_sync1, 1'b1};

// 系统复位保持计数器
parameter Counter_SET = 200;    // 最大计数值
parameter Counter_Reset = 100;  // 复位释放阈值 (2μs)
reg [7:0] Counter;
reg CounterEN;

always @(posedge Clk_50Mhz)
    if(reset_sync2) begin
        if(CounterEN)
            Counter <= (Counter < Counter_SET) ? Counter + 1 : 0;
        else
            Counter <= 0;
    end

// 复位输出 (高有效)
assign reset_sync = reset_sync2 && !(Counter > 0 && Counter <= Counter_Reset);
```

**关键时序参数**:
| 参数 | 值 | 说明 |
|------|-----|------|
| POR释放延迟 | ~5.08μs | 254 clk @ 50MHz |
| PLL稳定延迟 | ~1.28μs | 64 clk @ 50MHz |
| 系统复位最小脉宽 | 2μs | 100 clk @ 50MHz |
| 系统复位总保持 | 4μs | 200 clk @ 50MHz |

### 4.3 软件复位协议

通过向SafetyMonitor寄存器写入触发软件复位：
1. 写 `0xFFAA` 到 SafetyMonitor 偏移地址 `0x0003` (SysResetCTRL)
2. SafetyMonitor 将 `SysResetSig` 拉高
3. SysPLL 同步 `SysResetSig` 到 50MHz 域
4. 复位计数器从0计数到200
5. 前100周期(2μs)保持系统复位有效
6. 100周期后释放复位

## 6. 时钟域设计要点

### 6.1 为什么选择100MHz作为主时钟

- **PWM分辨率**: 8kHz载波, 100MHz时钟 → 12500 counts/周期 → 13.6位有效分辨率
- **死区时间精度**: 2μs死区 = 200 clk @ 100MHz, 精度 ±10ns
- **FOC计算带宽**: 单轴~21 clk @ 100MHz = 0.21μs, 远小于125μs PWM周期
- **Sinc3滤波器**: 需要20MHz独立时钟以匹配Σ-Δ调制器速率

### 6.2 同步设计原则

1. **所有模块使用同一复位源** (`reset_sync`), 确保同步释放
2. **单时钟沿设计**: 所有逻辑在 `posedge` 触发
3. **跨域信号**必须经过同步器后才能使用
4. **复位释放**在时钟沿同步，避免复位恢复时间违规
5. **PLL锁定前**不释放内部复位 (`init`信号控制)

## 7. 调试与验证

### 7.1 关键检查点

| 检查项 | 方法 | 预期结果 |
|--------|------|---------|
| PLL锁定 | 读PLL locked状态 | C0/C1/C2时钟稳定 |
| 复位释放 | 监测reset_sync | POR后~7μs释放 (5.08+1.28+2) |
| 时钟频率 | 频率计/示波器 | 50/100/20MHz ±100ppm |
| 跨域同步 | 时序报告 | 无跨clock group违例 |

### 7.2 自由运行计数器

SafetyMonitor中有一个32位自由运行计数器 (`FreeRunCNTer`), 其高位 `[22:7]` 可读。该计数器在 `clk100Mhz` 下连续运行, 可用于验证系统时钟是否正常工作。

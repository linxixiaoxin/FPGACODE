## 1. 产品概述

### 1.1 产品定位

本FPGA设计实现了一个**四轴永磁同步电机(PMSM)伺服驱动器**的完整FOC（磁场定向控制）电流环。FPGA作为协处理器，负责实时控制运算，通过外部总线与主控MCU（Renesas或STM32/GD32）通信。

### 1.2 核心功能

| 功能模块 | 描述 |
|---------|------|
| 四轴独立FOC控制 | Clarke/Park变换、PI电流调节、SVPWM调制 |
| 多编码器支持 | 增量式ABZ、绝对值BISS-C、通信式DMC |
| 高精度电流采样 | Delta-Sigma ADC + Sinc3数字滤波器 |
| 多总线接入 | Renesas异步总线、STM32/GD32 FSMC、SPI从机、UDP/RMII、Zlink |
| 安全保护 | IPM故障检测、过流保护、看门狗、STO |
| 辅助信号采集 | 多路编码器监控、通用信号采样 |

### 1.3 关键性能指标

| 指标 | 参数 |
|------|------|
| PWM载波频率 | 8 kHz (62.5 μs半周期) |
| 电流环控制周期 | 125 μs (与PWM同步) |
| 死区时间 | 2 μs |
| 最小脉宽 | 4 μs |
| 主系统时钟 | 100 MHz |
| ADC调制时钟 | 20 MHz |
| 编码器接口速率 | BISS-C: ~2.5 Mbps; DMC: ~2.5 Mbps |
| 通信接口 | 100Mbps RMII Ethernet, SPI 20MHz, 异步并行总线 |

## 4. 时钟与复位架构

### 4.1 时钟树

```
外部晶振 (50MHz 或 25MHz)
    │
    └── FPGA clk 输入引脚 (F1)
        │
        └── SysPLL (ESCPLL 硬IP)
            ├── C0: 50 MHz  (clk50Mhz) — 通用逻辑
            ├── C1: 100 MHz (clk100Mhz) — 主系统时钟
            └── C2: 20 MHz  (clk20Mhz) — ADC Sinc3滤波器 + 编码器慢速逻辑
```

### 4.2 时钟域

| 时钟域 | 频率 | 来源 | 用途 |
|--------|------|------|------|
| **CLK100Mhz** | 100 MHz | PLL C1 | FOC计算、SVPWM、总线矩阵、安全监控、寄存器接口 |
| **CLK50Mhz** | 50 MHz | PLL C0 | 通用逻辑 |
| **CLK20Mhz** | 20 MHz | PLL C2 | Delta-Sigma ADC Sinc3滤波器、编码器接口 |
| **PHY1REFCLK** | 50 MHz | 外部PHY | RMII PHY 0 接收时钟域 |
| **PHY2REFCLK** | 50 MHz | 外部PHY | RMII PHY 1 接收时钟域 |
| **SPICLK** | ~20 MHz | 外部SPI主控 | SPI从机采样时钟域 |

**时钟域处理策略**：
- 所有时钟组在SDC中声明为**互斥(exclusive)**，即视为完全异步
- 跨时钟域信号使用**双触发器同步器**（如复位信号、SPI到100MHz域）
- RMII PHY数据使用**异步FIFO（双端口SRAM）**进行跨时钟域传输
- ADC数据从20MHz域到100MHz域使用寄存器同步链

### 4.3 复位策略

```
上电复位 (AppEnvironment)
  │  CNT0[7:0] 计数 0→254, ~5.08μs后释放
  └── rstin (低有效复位脉冲)
      │
      └── SysPLL
          ├── 双触发器同步器 (CLK50Mhz域)
          ├── 复位保持计数器 (200周期 = 4μs)
          └── reset_sync → 全局系统复位
              │
              ├── SysResetSig 外部复位输入 (同步后)
              └── 复位输出至所有模块
```

**复位层次**：
1. **POR (上电复位)**: 由AppEnvironment的计数器自动生成，~254个时钟周期
2. **PLL锁定复位**: PLL内部areset由init计数器控制（63周期后释放）
3. **系统复位**: SysPLL输出的同步化、消抖复位，最小脉冲宽度100周期(2μs)
4. **外部复位**: SysResetSig引脚可通过SafetyMonitor软件复位系统

## 5. 总线互连架构

### 5.1 总线拓扑

```
                           外部总线主控
            ┌─────────────────┼─────────────────┐
            │                 │                 │
     Renesas 异步总线   STM32/GD32 FSMC     SPI 主控
     (地址/数据分离)    (地址/数据复用)    (Mode 3, 40-bit帧)
            │                 │                 │
     [AsyncRenesas]   [AsyncSTM32GD32]    [SlaveSPICtrl]
            │                 │                 │
            └─────────┬───────┴────────┬────────┘
                      │   Master1Sel   │
              ┌───────┴────[BusInterconnecter]───────┐
              │                │                      │
          Master1          Master2             内部主控 (Master2域)
              │                │               UART调试 / UDP / Zlink
              │        固定优先级仲裁                │
              │        (Master1 > Master2)   Master2Sel
              └────────┬───────┬───────────────┘
                       │       │
                 [AccessLocalspcae]
                 地址译码 → 8通道
                       │
        ┌──────┬──────┬─┴──┬──────┬──────┬──────┬──────┐
       Ch0    Ch1    Ch2  Ch3   Ch4    Ch5    Ch6    Ch7
      Debug  Curr   Pos   Axis Carrier Indir Safety Overall
     Reserve Sample Sample CTRL  Module  Sig   Monitor Control
```

### 5.2 总线协议

**内部总线信号（统一16位并行）：**

| 信号 | 宽度 | 方向 | 描述 |
|------|------|------|------|
| `ADDR` | 16 | Master→Slave | 基地址偏移（由AccessLocalspcae计算） |
| `WRDATA` | 16 | Master→Slave | 写数据 |
| `RDLWRH` | 1 | Master→Slave | 读/写选择 (1=读, 0=写) |
| `CS` | 1 | Master→Slave | 片选（地址命中时有效） |
| `RDDATA` | 16 | Slave→Master | 读数据 |
| `RDDATAVALID`/`WRACK` | 1 | Slave→Master | 读写应答握手 |

**访问延迟**: 2个时钟周期（地址译码1周期 + 数据返回1周期）

### 5.3 多主仲裁

- **仲裁策略**: 固定优先级，**Master1永远优先于Master2**
- **冲突处理**: 当两主同时访问时，Master2的请求被抑制一个时钟周期，延迟后重放
- **无公平性机制**: Master1连续访问时可能饿死Master2
- **访问源跟踪**: `AccessSource` 标志 (0=Master1, 1=Master2) 随流水线传递，确保应答信号路由到正确的主控

### 5.4 地址映射

| 通道 | 基地址 | 结束地址 | 大小 | 外设 |
|------|--------|---------|------|------|
| Ch0 | 0x0000 | 0x00FF | 256W | Debug/Reserve (Reservespace) |
| Ch1 | 0x0100 | 0x01FF | 256W | CurrentSample |
| Ch2 | 0x0200 | 0x02FF | 256W | PositionDetection |
| Ch3 | 0x0300 | 0x06FF | 1024W | AxisesCurrentCtrler |
| Ch4 | 0x0700 | 0x077F | 128W | CarrierModule |
| Ch5 | 0x0780 | 0x07FF | 128W | UnrelatedSigSample |
| Ch6 | 0x0800 | 0x087F | 128W | SafetyMonitor |
| Ch7 | 0x0880 | 0x08FF | 128W | OverAllControl (预留) |

### 5.5 外部总线接口

#### 5.5.1 Renesas 异步总线接口

- **协议**: 独立地址/数据总线，SRAM-like时序
- **关键信号**: CS(片选), RD(读选通), WE(写选通), NADV(地址有效), ADDR[15:0], DATA[15:0]
- **时序转换**: 边沿检测 → 内部脉冲生成（RD下降沿→读脉冲，WE上升沿→写脉冲）
- **同步链**: 3级触发器同步 + CS门控防误触发

#### 5.5.2 STM32/GD32 FSMC 接口

- **协议**: 地址/数据复用总线 (FSMC Mode)
- **关键差异**: 使用NADV信号锁存地址（NADV上升沿时DATA总线上为地址）
- **同步链**: 3级触发器延迟 + 边沿检测

#### 5.5.3 SPI 从机接口

- **SPI模式**: Mode 3 (CPOL=1, CPHA=1)
- **帧格式**: 40-bit事务
  - Bit 0-15: 地址[15:0] (MSB first)
  - Bit 16-17: 命令[1:0]
  - Bit 18: AccessMsgValid标志
  - Bit 19-23: 间隙
  - Bit 24-39: 写数据[15:0] (MSB first)
- **命令编码**: 00=无操作, 01=读, 10=写, 11=读写

### 5.6 Master1Sel / Master2Sel 配置

| 值 | Master1 前端 | Master2 前端 |
|----|-------------|-------------|
| 0 | 禁用 | 禁用 |
| 1 | **Renesas异步总线** (默认) | UART调试模块 |
| 2 | STM32/GD32 FSMC | **UDP/RMII** (默认) |
| 3 | SPI从机 | Zlink从站 |

## 6. FOC电机控制子系统

### 6.1 时序流水线

FOC计算由`ArithmeticScheduler`（位于`AxisesCurrentCtrler/ArithmeticScheduler.v`）以两级重叠流水线编排：

```
载波触发 (ACRTrig)
    │
    ▼
┌─────────────────────────────────────────────┐
│ 阶段1: MotorCurrentCtrler (逐轴顺序处理)      │
│                                             │
│  轴1: Clark(2) → Park(3) → PI×2(14)        │
│        → CircleLimit → Ipark(2)  = ~21 clk  │
│  轴2: (同上)                     = ~21 clk  │
│  轴3: (同上)                     = ~21 clk  │
│  轴4: (同上)                     = ~21 clk  │
│                                             │
│ 阶段2: SvpwmModulate (与阶段1重叠)            │
│  轴1..4: SVPWM计算 每个 ~11 clk              │
└─────────────────────────────────────────────┘
```

**关键时序参数**:
- PWM周期 = 125 μs (8kHz载波)
- 单轴FOC计算 ~21 clk @ 100MHz = 0.21 μs
- 四轴总计 < 2 μs，远小于PWM周期
- SVPWM与电机控制器流水线重叠，提高吞吐量

### 6.2 Clarke变换 (ClarkTrans.v)

```
输入: IU, IV (16-bit Q15, 有符号)
输出: IALPHA, IBETA (16-bit Q15)

算法:
  IALPHA = IU
  IBETA  = (IU + 2*IV) / sqrt(3)  使用HW_MULT_S1616乘法器
  
延迟: 2 clk
```

### 6.3 Park变换 (ParkTrans.v)

```
输入: IALPHA, IBETA, SINval, COSval (16-bit Q15)
输出: ID, IQ (16-bit Q15)

算法:
  ID = COSval * IALPHA + SINval * IBETA
  IQ = COSval * IBETA - SINval * IALPHA

实现: 分时复用两个HW_MULT_S1616乘法器
延迟: 3 clk
```

### 6.4 PI控制器 (PICtrler.v)

```
算法: 增量式PI

  e(k) = Ref - Fbk
  up(k) = Kp × e(k)                     (32×17 → 48-bit)
  ui(k) = Ki × e(k)                     (32×17 → 48-bit)
  UiAcc(k) = Clamp(UiAcc(k-1) + ui(k), ±Limit)
  PIResult = Clamp(up(k) + UiAcc(k) + Compensate, ±Limit)

数值格式:
  Kp, Ki: 32-bit Q15 (p.u.)
  Limit: 用户可配置
  积分累加器: 32-bit Q30 (无符号)

延迟: 7 clk
```

### 6.5 矢量控制器 (VectorCtrler.v)

```
状态机: IDLE → FirstPICAL → CircleLimitPRE → CircleLimitCAL
       → SecondPICAL → IPARKCAL_Ualpha → IPARKCAL_Ubeta → Calfinish

电压圆限制:
  R² = min(LimitCircleRadius_user, LimitCircleRadiusHW)
  先计算D轴PI输出 UD
  限制Q轴: UQ_max = sqrt(R² − UD²)
  或
  先计算Q轴PI输出 UQ
  限制D轴: UD_max = sqrt(R² − UQ²)
   (通过LimitMode_HDLQ选择)

反Park变换:
  UALPHA = COSval × UD − SINval × UQ
  UBETA  = SINval × UD + COSval × UQ
```

### 6.6 SVPWM调制 (SvpwmModulate.v)

```
算法: 七段式SVPWM

1. 扇区识别:
   Vref1 = UBETA
   Vref2 = UBETA/2 + UALPHA*sqrt(3)/2
   Vref3 = UBETA/2 − UALPHA*sqrt(3)/2
   扇区 = {Vref2[15], Vref3[15], ~Vref1[15]}

2. 时间计算:
   x = UBETA * (2*sqrt(3)/3)
   y = Vref2 * (2*sqrt(3)/3)
   z = Vref3 * (2*sqrt(3)/3)
   T1/T2 根据扇区从 {x,y,z} 中选择

3. 过调制检测: T1+T2 > 1.0 (Q15)

4. 占空比计算:
   ta = (1 − T1 − T2) / 2
   tb = ta + T1
   tc = ta + T1 + T2
   cmpX 根据扇区从 {ta,tb,tc} 分配
   DutyX = PeriodCNT − cmpX × PeriodCNT

电压圆限制常量: 0x6ED9 (≈ sqrt(3)/3 * Udc, Q15)

延迟: 11 clk
```

### 6.7 Sin/Cos计算 (SinCosCal.v)

```
算法: CORDIC (16次迭代)

相位归一化: [0, 360°) → [0, 90°), 记录象限

迭代:
  xn = x ± y>>n  (根据 z 的符号)
  yn = y ∓ x>>n
  zn = z ∓ arctan(1/2^n)

收敛系数: K = 16'h4DB9

象限恢复:
  Q0: sin=yn, cos=xn
  Q1: sin=xn, cos=-yn
  Q2: sin=-yn, cos=-xn
  Q3: sin=-xn, cos=yn
```

### 6.8 平方根 (Sqrt32.v)

```
算法: 逐次逼近法 (试位法)

迭代17次, 每次确定一个结果位
使用HW_MULT_S1616计算猜测值的平方
纯组合逻辑+寄存器实现, 无需专用IP

延迟: 17 clk
```

## 11. Zlink通信协议

### 11.1 协议栈层次

```
┌─────────────────────────────────────┐
│        应用层                        │
│  寄存器读写 (IndependentRead/Write)  │
├─────────────────────────────────────┤

├─────────────────────────────────────┤
│        拓扑发现层                    │

├─────────────────────────────────────┤
│        以太网MAC层                   │
│  MAC地址过滤 + CRC32校验             │
├─────────────────────────────────────┤
│        PHY物理层                     │
│  RMII 2-bit @ 50MHz → 1-bit @ 100MHz│
│  双端口 (Port 0 / Port 1)           │
└─────────────────────────────────────┘
```

### 11.2 帧格式

```
以太网帧:
┌──────────┬──────────┬──────────┬──────────────────────┬────────┐
│ 目的MAC  │ 源MAC    │ EtherType│ 载荷                  │ CRC32  │
│ (6字节)  │ (6字节)  │ (2字节)  │                      │ (4字节)│
└──────────┴──────────┴──────────┴──────────────────────┴────────┘

0x88A4 帧载荷:
┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┐
│SysRefClk │SlaveDetect│OpMode   │FrameIndex│DataLength│ 子报文   │
│(4字节)   │(1字节)   │(1字节)  │(2字节)   │(2字节)   │ ...      │
└──────────┴──────────┴──────────┴──────────┴──────────┴──────────┘

子报文:
┌──────┬──────────┬───────────┬───────────┬──────────┐
│ CMD  │SlaveAddr │LocalAddr  │DataLength │ NextFlag │ 数据... │
│(1B)  │(1B)      │(2B)       │(15b)      │ (1b)     │         │
└──────┴──────────┴───────────┴───────────┴──────────┘
```

### 11.3 拓扑管理

```
菊花链拓扑 (每个节点有两个PHY端口):

  Master ── Port0 [Zlink Node] Port1 ── Port0 [Next Node] Port1 ── ...

工作模式 (基于Linkstate[1:0]):
  "10": Port0发送本地TX, Port1禁用
  "11": Port0 转发 Port1的RX (下游), Port1 发送本地TX (上游)
  "01": Port0禁用, Port1 自环回

从站检测: 
  每个节点在转发时对SlaveDetect字节+1, 主控通过最终值获知链上节点数
```

### 11.4 在线读取机制

```
"在线读取" (In-Stream Read):
  读取请求在子报文中发出后, 
  响应数据直接在转发帧的对应位置替换写入
  无需等待独立的响应帧 → 确定性延迟, 适合实时控制
```

### 11.5 CRC32

```
多项式: 0x04C11DB7 (标准 Ethernet CRC-32)
实现: 256项查找表
最终结果: 按位取反 (~crc_temp)
```

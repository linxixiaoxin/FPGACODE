# 04 — 电流采样系统技术开发文档

> **所属项目**: AxisesCTRL (四轴伺服驱动器 FPGA)  
> **涉及目录**: `CurrentSample/`  
> **关键模块**: CurrentSample, ADCsDriver, Sinc3Driver, CurrentForACR, AllCurrentMonitor, MotorCurrentMonitor, RegSpcae_CurrentSample

---

## 1. 模块概述

电流采样系统负责将外部 Σ-Δ ADC 的 1-bit 码流解码为 16-bit 有符号电流值，提供锁存后的数据给 FOC 电流控制器，并实时监控过流状态。

### 1.1 设计指标

| 参数 | 值 |
|------|-----|
| ADC类型 | Σ-Δ 调制器 (AD7401或同等) |
| 调制器时钟 | 20 MHz (DSASCCLK) |
| 滤波器类型 | 3阶 Sinc3 |
| 抽取比 | 128:1 |
| 输出速率 | 156.25 kHz (20MHz / 128) |
| 输出精度 | 16-bit (内部25-bit) |
| 采样通道 | 8路 (4轴 × 2相 U/V) |

### 1.2 模块层次

```
CurrentSample.v
├── RegSpcae_CurrentSample.v      ← 寄存器接口 (9 reg/轴 × 4轴)
├── ADCsDriver.v                  ← ADC驱动器 (8×Sinc3 + W相计算)
│   └── Sinc3Driver.v ×8         ← Sinc3滤波器
├── AllCurrentMonitor.v           ← 过流监控组合
│   └── MotorCurrentMonitor.v ×4  ← 单轴过流检测
└── CurrentForACR.v               ← ACR数据同步锁存
```

## 2. 信号链数据流

```
外部 Σ-Δ ADC (8通道)
  │  1-bit 码流 @ 20MHz
  ▼
┌──────────────────────────────────────────┐
│ ADCsDriver.v                              │
│                                            │
│  Axis1_IUBitin → Sinc3Driver → IUW_pre   │
│  Axis1_IVBitin → Sinc3Driver → IV_pre    │
│  IU = -(IUW_pre + IV_pre)  星形推导      │
│  clamp(IU, ±32767)                        │
│                                            │
│  ... (Axis2/3/4 同理)                     │
└──────────────┬───────────────────────────┘
               │ AxisN_IU[15:0], AxisN_IV[15:0]
               ▼
┌──────────────────────────────────────────┐
│ CurrentForACR.v                           │
│  在 ACRLockTrig 上升沿锁存全部8通道        │
│  输出 AxisN_IU/IV_Locked + DataLockedPluse│
└──────────────┬───────────────────────────┘
               │ → FOC (AxisesCurrentCtrler)
               ▼
┌──────────────────────────────────────────┐
│ AllCurrentMonitor.v                       │
│  实时比较 IU/IV/IW vs IMax/IMin          │
│  输出 AxisN_OC → SafetyMonitor           │
└──────────────────────────────────────────┘
```

## 3. ADCsDriver (ADCsDriver.v) — 核心算法

### 3.1 模块接口

| 端口 | 方向 | 位宽 | 描述 |
|------|------|------|------|
| `clk100Mhz` | in | 1 | 100MHz系统时钟 (寄存器同步) |
| `clk20Mhz` | in | 1 | 20MHz Σ-Δ调制器时钟 |
| `DSASCCLK` | out | 1 | = clk20Mhz (直通给外部ADC) |
| `AxisN_IUBitin` | in | 1 | 轴N U相 Σ-Δ 1-bit输入 |
| `AxisN_IVBitin` | in | 1 | 轴N V相 Σ-Δ 1-bit输入 |
| `AxisN_polarity[1:0]` | in | 2 | 极性控制: bit0=IU, bit1=IV |
| `AxisN_IU/IV_Offset[15:0]` | in | 16 | 偏移量校正值 |
| `AxisN_IU[15:0]` | out | 16 | 最终U相电流 (有符号) |
| `AxisN_IV[15:0]` | out | 16 | 最终V相电流 (有符号) |

### 3.2 IU推导 (星形连接W相计算)

```verilog
// Sinc3输出:
Axis1_IUW_pre  ← Sinc3Driver(IUBitin)   // U相原始值
Axis1_IV_pre   ← Sinc3Driver(IVBitin)   // V相原始值

// 星形连接推导IU:
// IUW_pre 是U相绕组的电流 (编码在Σ-Δ中)
// 真正的 IU = -(IUW_pre + IV_pre)
// 因为三相平衡系统中 IU + IV + IW = 0
Axis1_IU_pre = -($signed(Axis1_IUW_pre)) - ($signed(Axis1_IV_pre));
```

### 3.3 饱和限幅

```verilog
// 每个轴的IU经过限幅处理
wire [16:0] IU_expand = {AxisN_IU_pre[16], AxisN_IU_pre}; // 17-bit

case (IU_expand[16:15])
    2'b10:  AxisN_IU_act = -16'd32767;   // 负溢出 → -32767
    2'b01:  AxisN_IU_act = 16'd32767;    // 正溢出 → +32767
    default: AxisN_IU_act = AxisN_IU_pre[15:0]; // 正常
endcase
```

### 3.4 220V版本的特殊处理

```
最新220V版本适配说明 (来自 不同硬件版本对应的程序修改说明.txt):
  "原来采样U相的引脚用于采样W相，即将UV相采样变更为WV相采样"

这意味着在 ADCsDriver.v 中:
  AxisN_IU_act 的连接源从 IUW_pre 切换为其他通道
  具体修改位置: Axis*_IU_act 信号赋值
```

## 4. Sinc3滤波器 (Sinc3Driver.v) — 核心算法

### 4.1 Sinc3数学原理

3阶 Sinc3 滤波器的传递函数:
```
H(z) = [(1 - z^(-M)) / (1 - z^(-1))]^3
```
其中 M = 128 (抽取比)

等效于: 3级积分器 → 128:1抽取 → 3级差分器

### 4.2 硬件结构

```
clk20Mhz 域:                     clk100Mhz 域:
                                  
data ─→ [+]─→ [+]─→ [+]─→ RAM ─→ [-]─→ [-]─→ [-]─→ DataOut
         ↑      ↑      ↑    128×25    ↑      ↑      ↑
        acc1   acc2   acc3         ram_dly1 ram_dly2 ram_dly3
```

### 4.3 积分器阶段 (20MHz域)

```verilog
// 1-bit → 25-bit 扩展
wire [24:0] ip_data1 = {24'd0, mdata1};  // 0 或 1

// 三级级联累加器
reg [24:0] acc1, acc2, acc3;
always @(posedge clk20Mhz or negedge rst) begin
    if (!rst) begin
        acc1 <= 0; acc2 <= 0; acc3 <= 0;
    end else begin
        acc1 <= acc1 + ip_data1;
        acc2 <= acc2 + acc1;
        acc3 <= acc3 + acc2;
    end
end
```

### 4.4 抽取与梳状阶段 (RAM操作)

```verilog
// 每128个输入时钟执行一次读-改-写RAM操作
// count_ram: 0→127 循环

// 锁存 acc3
acc3_Lock <= acc3;  // 抽取时刻的积分器值

// RAM存储 (写端口):
WRDATA = acc3_Lock;
WRADDR = count_ram;

// 读回2周期前的值:
ram_acc3_d2  <= RAM[count_ram];  // 2周期延迟
ram_diff1_d2 <= ram_diff1;       // 差分级联
ram_diff2_d2 <= ram_diff2;

// 差分计算:
ram_diff1 <= acc3_Lock - ram_acc3_d2;
ram_diff2 <= acc3_Lock - ram_acc3_d2 - ram_diff1_d2;
ram_diff3 <= acc3_Lock - ram_acc3_d2 - ram_diff1_d2 - ram_diff2_d2;
```

### 4.5 输出处理

```verilog
// 位截取 (从25-bit → 17-bit, 等效缩放)
wire [16:0] DataOutpre0 = ram_diff3[21:5];  // 17-bit

// 极性处理
wire [16:0] DataOutpre1 = polarity ? 
    DataOutpre0 - 17'd32768 :   // 正向
    17'd32768 - DataOutpre0;    // 反向

// 偏移量校正
wire [16:0] Dataotput_expand = DataOutpre1 + {Offset[15], Offset};

// 最终限幅
if (Dataotput_expand[16:15] == 2'b10)      DataOut <= 16'h8000;  // 负溢出
else if (Dataotput_expand[16:15] == 2'b01) DataOut <= 16'h7FFF;  // 正溢出
else                                        DataOut <= Dataotput_expand[15:0];
```

### 4.6 跨时钟域同步

```
20MHz 域 → 100MHz 域:

DataValid (clk20Mhz) → DataValid_sync0 (clk100Mhz)
                     → DataValid_sync1 (clk100Mhz)
                     → DataValid_sync2 (clk100Mhz)

// 边沿检测
wire DataValid_Redge = DataValid_sync1 && !DataValid_sync2;

// 在边沿锁存数据
if (DataValid_Redge)
    DataOut_locked <= DataOut;
```

## 5. ACR数据锁存 (CurrentForACR.v)

### 5.1 功能

在 `ACRLockTrig` 脉冲的上升沿一次性锁存所有8个通道的电流值:

```verilog
always @(posedge clk) begin
    if (ACRLockTrig) begin
        Axis1_IU_Locked <= Axis1_IU;
        Axis1_IV_Locked <= Axis1_IV;
        Axis2_IU_Locked <= Axis2_IU;
        // ... (全部8个通道)
    end
end

assign DataLockedPluse = ACRLockTrig;
```

**设计意义**: 确保FOC计算使用的电流值采样于同一时刻，避免计算中数据不一致。

## 6. 过流监控 (AllCurrentMonitor + MotorCurrentMonitor)

### 6.1 MotorCurrentMonitor (单轴)

```verilog
// 扩展为17-bit带符号
wire [16:0] IU_expand = {IU[15], IU};
wire [16:0] IV_expand = {IV[15], IV};
wire [16:0] IW_expand = -IU_expand - IV_expand;  // 基尔霍夫推导

wire [16:0] IMax_expand = {IMax[15], IMax};
wire [16:0] IMin_expand = {IMin[15], IMin};

// 任一相超出阈值则置位OC
assign OC = (IU_expand > IMax_expand) || (IU_expand < IMin_expand) ||
            (IV_expand > IMax_expand) || (IV_expand < IMin_expand) ||
            (IW_expand > IMax_expand) || (IW_expand < IMin_expand);
```

### 6.2 AllCurrentMonitor

简单地将4个 `MotorCurrentMonitor` 实例化并输出各自的 `OC` 信号到 `SafetyMonitor`。

## 7. 寄存器地址映射

### 7.1 通道基地址: `0x0100`

### 7.2 每轴寄存器 (9个寄存器 × 4轴)

| 偏移 | 名称 | 位宽 | R/W | 复位值 | 描述 |
|------|------|------|-----|--------|------|
| 0x00 | IU_Offset | 16 | R/W | 0 | U相偏移量校正 (有符号) |
| 0x01 | IV_Offset | 16 | R/W | 0 | V相偏移量校正 (有符号) |
| 0x02 | polarity | 16 | R/W | 0 | bit0=IU极性 bit1=IV极性 (1=正) |
| 0x03 | IU (实时) | 16 | R | — | 实时U相电流 |
| 0x04 | IV (实时) | 16 | R | — | 实时V相电流 |
| 0x05 | IMax | 16 | R/W | 32767 | 过流上限阈值 (有符号) |
| 0x06 | IMin | 16 | R/W | -32767 | 过流下限阈值 (有符号) |
| 0x07 | IU_Locked | 16 | R | — | ACR锁存的U相电流 |
| 0x08 | IV_Locked | 16 | R | — | ACR锁存的V相电流 |

### 7.3 轴地址

| 轴 | 偏移起始 | 偏移结束 |
|----|---------|---------|
| Axis1 | 0x000 | 0x008 |

## 8. 电流采样时序

```
PWM载波     /\              /\
           /  \            /  \
          /    \          /    \
         /      \        /      \
  ──────┴────────┴──────┴────────┴──

ACRTrig ──────┐        ┌──────────
              └────────┘  (极值前250clk = 2.5μs)
              
Sinc3输出    ← 连续更新 (156.25kHz) →
              
DataLocked  ──────┐        ┌──────────
 (锁存时刻)       └────────┘

FOC计算             ├─21clk─┤
                    (0.21μs)

PWM更新             ├─┤ (载波极值处)
```

**关键参数**:
- `ACRTrigLead = 250` clk = 2.5 μs (在载波极值前触发)
- Sinc3滤波器群延迟 = 约 3×(128-1)/2 / 20MHz = 约 9.5 μs
- FOC计算完成到PWM更新的裕量 = 2.5 μs - 0.21 μs ≈ 2.3 μs

## 9. 校准与调试

### 9.1 偏移量校准步骤

1. 电机不供电，各相电流理论值为0
2. 读取 `IU` (0x03) 和 `IV` (0x04) 实时值
3. 将读取值的相反数写入 `IU_Offset` (0x00) 和 `IV_Offset` (0x01)
4. 重新读取确认归零

### 9.2 极性验证

- `polarity=0`: 驱动器→电机 (正向电流)
- `polarity=1`: 电机→驱动器 (反向/发电)

### 9.3 过流阈值设置

- `IMax`: 通常设为额定电流的2-3倍
- `IMin`: 通常设为 -IMax

## 10. 设计注意事项

1. **Sinc3滤波器固有的群延迟**约10μs，在系统建模时需考虑
2. **20MHz时钟**需要低抖动，直接影响ADC SNR
3. **Sinc3 RAM初始化**需要在复位后写入128个零值，确保滤波器从已知状态开始
4. **跨时钟域**从20MHz到100MHz使用三级同步+边沿检测，确保数据可靠传输
5. **W相推导**假设三相平衡系统 (IU+IV+IW=0)，在电机故障时可能不准确

> **涉及目录**: `UnrelatedSigSample/`, `Reservespace/`  
> **关键模块**: UnrelatedSigSample, DriversMux, LiteDMCProtocol_Monitor, RegSpcae_UnrelatedSigSample, Reservespace, RegSpcae_Reservespace

## 一、辅助信号采集 (UnrelatedSigSample)

### 1. 模块概述

辅助信号采集模块处理与FOC主控制回路不直接相关的信号，包括：
- VBUS直流母线电压采样（通过 Σ-Δ ADC + Sinc3 滤波）
- 16路通用数字输入/输出
- 两路额外的DMC编码器位置反馈监听（A侧和D侧RS-485）

### 2. 模块层次

```
UnrelatedSigSample.v
├── RegSpcae_UnrelatedSigSample.v   ← 寄存器接口
├── DriversMux.v                    ← VBUS ADC + 数字IO
└── LiteDMCProtocol_Monitor.v ×2    ← 两侧DMC位置监听
    └── UARTServiceForDMC.v
```

### 3. 信号接口

| 端口 | 方向 | 位宽 | 描述 |
|------|------|------|------|
| `clk100Mhz` | in | 1 | 系统时钟 |
| `clk20Mhz` | in | 1 | Sinc3时钟 |
| `VBUSClk` | out | 1 | VBUS ADC时钟 (= clk20Mhz) |
| `VBUSDataIn` | in | 1 | VBUS Σ-Δ 1-bit码流 |
| `DigitalInput[15:0]` | in | 16 | 外部数字输入 |
| `DigitalOutput[15:0]` | out | 16 | 数字输出 |
| `ASide_SD` | in | 1 | A侧DMC 485接收数据 |
| `ASide_RQ` | out | 1 | A侧DMC 485发送数据 |
| `ASide_DRCNT` | out | 1 | A侧DMC 485方向控制 |
| `DSide_SD` | in | 1 | D侧DMC 485接收数据 |
| `DSide_RQ` | out | 1 | D侧DMC 485发送数据 |
| `DSide_DRCNT` | out | 1 | D侧DMC 485方向控制 |

### 4. DriversMux — VBUS采样与数字IO

#### 4.1 VBUS电压采样

```verilog
// VBUS ADC时钟 = clk20Mhz (直接输出)
assign VBUSClk = clk20Mhz;

// VBUS数据通过Sinc3Driver解码
// 参数: polarity=1 (固定正极性), Offset=0 (无偏移)
Sinc3Driver VBUS_Sinc3 (
    .clk20Mhz(clk20Mhz),
    .clk100Mhz(clk100Mhz),
    .mdata1(VBUSDataIn),
    .polarity(1'b1),
    .Offset(16'd0),
    .DataOut(Vbus)
);
```

#### 4.2 数字IO同步

```verilog
// 输入: 两级同步器消除亚稳态
reg [15:0] DI_sync0, DI_sync1;
always @(posedge clk) begin
    DI_sync0 <= DigitalInput;
    DI_sync1 <= DI_sync0;
end
assign DIs = DI_sync1;

// 输出: 直接从寄存器空间驱动
assign DigitalOutput = DOs;
```

### 5. LiteDMCProtocol_Monitor — DMC位置监听

#### 5.1 功能

被动监听DMC协议总线上的位置反馈数据，不主动发起请求。与PositionDetection中的DMC模块的区别：
- PositionDetection DMC: **主动**发送请求，接收响应
- Monitor DMC: **被动**监听，仅接收

#### 5.2 协议解析

```
DMC帧字节流:
  Byte0: (帧头/前导)
  Byte1: (帧头/前导)
  Byte2: PositionFB[7:0]   LSB
  Byte3: PositionFB[15:8]
  Byte4: PositionFB[23:16] MSB
  Byte5+: (尾部/校验)

PositionFB = {8'd0, Byte4, Byte3, Byte2}  // 24-bit → 32-bit
```

#### 5.3 字节间超时

```verilog
// ByteIntervalMax = 600 (6μs @ 100MHz)
// 超过6μs无新字节 → 视为帧结束, 重置字节计数器
reg [15:0] ByteIntervalCNT;
if (RxedPluse)
    ByteIntervalCNT <= 0;
else if (ByteIntervalCNT < ByteIntervalMax)
    ByteIntervalCNT <= ByteIntervalCNT + 1;
else
    RXByteCNT <= 0;  // 超时重置
```

#### 5.4 485方向控制

```verilog
assign DMC_DE = 1'b0;   // 始终为接收模式 (不发送)
assign DMC_OUT = 1'b1;  // 发送线保持高电平 (空闲状态)
```

### 6. 寄存器地址映射

#### 6.1 通道基地址: `0x0780`

#### 6.2 寄存器表

| 偏移 | 名称 | 位宽 | R/W | 描述 |
|------|------|------|-----|------|
| 0x00 | Vbus | 16 | R | VBUS直流母线电压值 (Sinc3解码后) |
| 0x01 | DIs | 16 | R | 同步后的数字输入状态 |
| 0x02 | DOs | 16 | R/W | 数字输出控制 |
| 0x04 | PositionFB_Aside_H | 16 | R | A侧DMC位置[31:16] |
| 0x05 | PositionFB_Aside_L | 16 | R | A侧DMC位置[15:0] (读0x04时锁存) |
| 0x06 | PositionFB_Dside_H | 16 | R | D侧DMC位置[31:16] |
| 0x07 | PositionFB_Dside_L | 16 | R | D侧DMC位置[15:0] (读0x06时锁存) |

#### 6.3 32位读一致性锁存

```verilog
// 读高位时锁存低位 (防止数据在两次读取间变化)
reg [15:0] PositionFB_Aside_L_locked;
reg [15:0] PositionFB_Dside_L_locked;

always @(posedge clk) begin
    if (CS && !RDLWRH && ADDR == 4)  // 读A侧高位
        PositionFB_Aside_L_locked <= PositionFB_Aside[15:0];
    if (CS && !RDLWRH && ADDR == 6)  // 读D侧高位
        PositionFB_Dside_L_locked <= PositionFB_Dside[15:0];
end

// 读低位时返回锁存值
assign RDDATA = (ADDR == 5) ? PositionFB_Aside_L_locked :
                (ADDR == 7) ? PositionFB_Dside_L_locked : ...;
```

## 二、保留空间 (Reservespace)

### 7. 模块概述

Reservespace 是一个通用的16×16-bit RAM空间，用于调试、参数存储或未来扩展。

### 8. 模块结构

```
Reservespace.v
└── RegSpcae_Reservespace.v
    └── SimpleDualPortRAM (16位宽 × 16深度)
```

### 9. 寄存器接口

| 端口 | 方向 | 位宽 | 描述 |
|------|------|------|------|
| `CS` | in | 1 | 片选 |
| `RDLWRH` | in | 1 | 读/写选择 |
| `ADDR[15:0]` | in | 16 | 地址 (仅低4位有效) |
| `WRDATA[15:0]` | in | 16 | 写数据 |
| `RDDATA[15:0]` | out | 16 | 读数据 |

### 10. 地址映射 (通道基地址: `0x0000`)

| 偏移 | 名称 | R/W | 描述 |
|------|------|-----|------|
| 0x00 - 0x0F | RAM[0..15] | R/W | 16个通用16-bit存储位置 |

**注意**: 该地址空间在总线分配中预留了256个字(0x0000-0x00FF)，但当前仅实现了16个位置(0x0-0xF)。超出范围的地址读回0。

# 10 — 系统顶层集成技术开发文档

> **所属项目**: AxisesCTRL (四轴伺服驱动器 FPGA)  
> **涉及文件**: `AppEnvironment.v`, `FourAxisesDriver.v`  
> **目标器件**: Anlogic EG4X20BG256

---

## 1. 模块概述

系统顶层由两层组成：
- **AppEnvironment.v** — FPGA引脚级顶层，负责物理IO映射、极性处理、上电复位
- **FourAxisesDriver.v** — 内部逻辑顶层，负责所有功能模块的实例化与互联

### 1.1 层次关系

```
FPGA引脚边界
└── AppEnvironment.v (顶层, 物理IO)
    └── FourAxisesDriver.v (内部顶层, 功能集成)
        ├── SysPLL              ← 时钟+复位
        ├── BusInterconnecter   ← 总线矩阵
        ├── CarrierModule       ← PWM载波
        ├── CurrentSample       ← 电流采样
        ├── PositionDetection   ← 位置检测
        ├── AxisesCurrentCtrler ← FOC控制
        ├── SafetyMonitor       ← 安全保护
        ├── UnrelatedSigSample  ← 辅助信号
        └── Reservespace        ← 保留空间
```

## 2. AppEnvironment.v — FPGA引脚级顶层

### 2.1 设计职责

| 职责 | 描述 |
|------|------|
| I/O引脚映射 | 142个引脚连接到内部模块端口 |
| 上电复位生成 | 254时钟周期计数器生成POR |
| 信号极性处理 | PWMEN→PWMEN_L, IPMFo_L→IPMFo取反 |
| 三态总线控制 | 双向异步数据总线的OE控制 |
| 硬件版本适配 | 48V/220V相序切换, 地址移位 |
| 调试捕获 | 异步总线信号寄存 (keep属性) |

### 2.2 上电复位 (POR)

```verilog
reg [7:0] CNT0;
always @(posedge clk) begin
    if (CNT0 != 8'd254)
        CNT0 <= CNT0 + 1'b1;
end
wire rstin = (CNT0 == 8'd254);  // ~5.08μs后释放
```

### 2.3 三态总线控制

```verilog
// 仅在MCU读操作时驱动数据总线
assign AsyncDATABus = (!AsyncCS && !AsyncRD) ? AsyncDATABus_out : 16'hzzzz;
```

### 2.4 PWM极性反转

```verilog
assign A_PWMEN_L = !A_PWMEN;  // 外部低有效
assign B_PWMEN_L = !B_PWMEN;
assign C_PWMEN_L = !C_PWMEN;
assign D_PWMEN_L = !D_PWMEN;
```

### 2.5 IPM故障极性反转

```verilog
// 外部信号: A_IPMFo_L (低有效)
// 内部信号: A_IPMFo (高有效故障)
.A_IPMFo(!A_IPMFo_L),
.B_IPMFo(!B_IPMFo_L),

```

### 2.6 地址总线移位

```verilog

```
MCU字节地址 → FPGA 16-bit字地址转换。


### 3.3 数据流连接矩阵

#### 3.3.1 时间触发链

```
CarrierModule → EncoderTrig  → PositionDetection (RequestTrig)
              → ACRTrig      → CurrentSample (ACRLockTrig)
                             → PositionDetection (TimeCriticalPluse)
              → ZEROTrig ─┐
              → PeriodTrig ┤→ BusInterconnecter (DealBaseTrig = ZEROTrig || PeriodTrig)
              → INTOut     → MCU (INT2MCU)
```

#### 3.3.2 电流环数据流

```
CurrentSample            AxisesCurrentCtrler        CarrierModule
  AxisN_IU/IV_Locked ──→ IU/IV (FOC输入)
  DataLockedPluse     ──→ trig (FOC启动)
                                                      AxisN_DutyA/B/C (输出)
PositionDetection                                ←──  轴占空比
  AxisN_SIN/COS       ──→ SINval/COSval
  AxisN_InvS/InvC     ──→ InvSINval/InvCOSval
                              ↓ FOC计算
                         AxisN_DutyA/B/C ────────→ DutyA/B/C
                         AxisN_CalEN    ←────────  CalEN (PWMEN && !Bootstrap)
```

#### 3.3.3 安全互锁链

```
CurrentSample → AxisN_OC         → SafetyMonitor
外部引脚      → AxisN_IPMFo_L     → SafetyMonitor
              → (经AppEnvironment取反为IPMFo)

SafetyMonitor → AxisN_PWMUNLOCK  → CarrierModule → 控制PWM输出
              → AxisN_PWMEN      → CarrierModule → 通道使能
              → STOout           → 外部引脚 (预留)
              → SysResetSig      → SysPLL (系统复位)
```

### 3.4 关键信号汇总

| 信号 | 宽度 | 源模块 | 目标模块 | 描述 |
|------|------|--------|---------|------|
| `clk` / `rstin` | 1 | 外部引脚 / AppEnv | SysPLL | 原始时钟+复位 |
| `clk100Mhz` / `clk50Mhz` / `clk20Mhz` | 1 | SysPLL | 所有模块 | 系统时钟 |
| `rst` | 1 | SysPLL | 所有模块 | 同步系统复位 |
| `EncoderTrig` | 1 | CarrierModule | PositionDetection | 编码器读触发 |
| `ACRTrig` | 1 | CarrierModule | CurrentSample, PositionDetection | FOC触发 |
| `ZeroPluse` / `PeriodPluse` | 1 | CarrierModule | BusInterconnecter | 调试帧触发 |
| `INTOut` | 1 | CarrierModule | MCU | 同步中断 |
| `DataLockedPluse` | 1 | CurrentSample | AxisesCurrentCtrler | 电流就绪 |
| `AxisN_IU/IV_Locked` | 16×8 | CurrentSample | AxisesCurrentCtrler | 锁存电流 |
| `AxisN_SIN/COS/Inv` | 16×16 | PositionDetection | AxisesCurrentCtrler | 角度sin/cos |
| `AxisN_DutyA/B/C` | 16×12 | AxisesCurrentCtrler | CarrierModule | PWM占空比 |
| `AxisN_CalEN` | 1×4 | CarrierModule | AxisesCurrentCtrler | 计算使能 |
| `AxisN_PWMUNLOCK` | 1×4 | SafetyMonitor | CarrierModule | 安全解锁 |
| `AxisN_OC` | 1×4 | CurrentSample | SafetyMonitor | 过流故障 |
| `AxisN_IPMFo` | 1×4 | 外部引脚 | SafetyMonitor | IPM故障 |
| `CounterPeriod` | 16 | CarrierModule | AxisesCurrentCtrler | 载波周期(=6249) |

### 3.5 共享资源

| 资源 | 共享方式 | 使用者 |
|------|---------|--------|
| `CounterCNT[15:0]` | 广播 | CarrierGen → 4×PwmGen → AxisesCurrentCtrler |
| `CounterDIR` | 广播 | CarrierGen → 4×PwmGen |
| `CounterPeriod[15:0]` (=6249) | 广播 | CarrierGen → 4×PwmGen → AxisesCurrentCtrler |
| `DSASCCLK` (=clk20Mhz) | 广播 | CurrentSample → 8个外部ADC CLK引脚 |
| `RDLWRH/ADDR/WRDATA` | 总线 | BusInterconnecter → 8个从设备 |
| `rst` | 星形 | SysPLL → 所有模块 |

### 5.3 器件资源利用 (估算)

基于EG4X20BG256 (20K LUTs):
- Sinc3滤波器 ×8: ~400 LUTs/个 = 3,200 LUTs
- FOC计算 (含SVPWM, 4轴): ~3,000 LUTs
- Zlink协议栈: ~2,500 LUTs
- UDP/RMII模块 (网表): ~3,000 LUTs
- 调试模块 (网表): ~800 LUTs
- 总线 + 寄存器 + PWM + 安全: ~2,500 LUTs
- **总计估算**: ~15,000 LUTs (~75%利用率)

## 7. 硬件版本管理

### 7.1 版本差异总结

| 版本 | 输入时钟 | PWM相序 | 电流采样 | Master2 | PHY0使用 |
|------|---------|---------|---------|---------|---------|

### 7.2 修改检查清单 (切换版本时)

1. ☐ `AppEnvironment.v`: PWM相序映射 (220V/48V)
2. ☐ `IOConstraint.adc`: 时钟输入引脚 (F1 → K14?)
3. ☐ `AnlogicPLL.ipc`: PLL输入时钟配置 (100MHz/25MHz)
4. ☐ `TimeConstraint.sdc`: CLKin周期 (10ns/40ns)
5. ☐ `AppEnvironment.v`: Master2Sel值 (2/3)
6. ☐ `BusInterconnecter.v`: PHY0接口启用/屏蔽
7. ☐ `ADCsDriver.v`: 电流通道映射 (UV/WV)
